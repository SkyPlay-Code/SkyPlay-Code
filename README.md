### 👁‍🗨 The Philosophy 
Most developers write code to tell a computer what to do. I write code to map out ideas, solve micro-localized problems, and dissect how systems work from the ground up. Whether it's translating academic concepts into algorithmic scripts or reverse-engineering decentralized systems, my repositories are an open timeline of persistent curiosity.

---

### 🚀 Selected Projects

Here are a few highlights from my public repositories, categorized by domain:

#### 💠 Systems, Networking & Graphics
I enjoy building the mechanics behind the interface to understand how systems function under the hood.
*   **`js-graphic-engine`**: A raw, vanilla JavaScript graphics rendering engine built from scratch to explore 3D math and rendering without external libraries.
*   **`py-blockchain` & `bittorrent-py`**: Implementations of a custom blockchain ledger in Python and the core logic of P2P BitTorrent networks. 
*   **`InstaTUI` & `ig-chat-exporter`**: Interactive Terminal User Interfaces (TUI) in Python designed for local data scraping and rapid terminal navigation.

#### 🛡 Automation
Practical tools leveraging automation.
*   **`python` Utility Hub**: A master collection of personal automation scripts focusing on file conversion, OS utilities, and OpenCV-based computer vision.

#### 🌱 Local Context & Educational Tools
I believe software should solve immediate, real-world problems for the community.
*   **`x-mark` & `MarkPrediction`**: A statistical analysis tool built to track and predict academic performance metrics for local student cohorts. 
*   **`12ncert`**: Specialized digital environments and tools tailored for Indian academic preparation.
